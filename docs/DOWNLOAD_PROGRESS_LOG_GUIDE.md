# 下载进度条详细日志功能说明

**功能添加时间**: 2025-11-20
**修改文件**: `templates/preview.html`
**功能类型**: 用户体验增强

---

## 📋 功能概述

在下载进度条中添加了详细的日志显示功能，让用户可以实时查看下载过程中的每一步操作，包括：
- 下载开始
- 路径配置
- API 调用
- 文件传输
- 错误处理
- 完成状态

5. **时间戳**
   - 精确到毫秒（HH:mm:ss.SSS）
   - 便于追踪操作时序

## 🔧 技术实现

### 新增函数

#### 1. `toggleDownloadLog()`

切换日志显示/隐藏状态

```javascript
function toggleDownloadLog() {
    const logContainer = document.getElementById('downloadLogContainer');
    const toggleText = document.getElementById('logToggleText');

    if (logContainer) {
        const isExpanded = logContainer.style.maxHeight !== '0px';

        if (isExpanded) {
            // 收起
            logContainer.style.maxHeight = '0';
            toggleText.textContent = '展开';
        } else {
            // 展开
            logContainer.style.maxHeight = '250px';
            toggleText.textContent = '收起';

            // 自动滚动到底部
            setTimeout(() => {
                logContainer.scrollTop = logContainer.scrollHeight;
            }, 100);
        }
    }
}
```

#### 2. `addDownloadLog(message, type)`

添加日志条目

**参数**：
- `message` (string): 日志消息内容
- `type` (string): 日志类型，可选值：
  - `'info'` - 信息（蓝色）
  - `'success'` - 成功（绿色）
  - `'warning'` - 警告（黄色）
  - `'error'` - 错误（红色）
  - `'debug'` - 调试（灰色）

**功能**：
- 创建日志条目并添加到日志容器
- 自动添加时间戳
- 自动滚动到底部
- 同时输出到浏览器控制台

**示例**：
```javascript
addDownloadLog('开始下载草稿', 'info');
addDownloadLog('下载成功！', 'success');
addDownloadLog('直接下载失败，尝试代理', 'warning');
addDownloadLog('下载失败：网络错误', 'error');
```

### 日志记录点

在下载流程的关键位置添加了日志记录：

| 步骤 | 日志内容 | 类型 |
|------|----------|------|
| 开始 | `开始下载草稿: ${draftId}` | info |
| 路径检测 | `使用自定义路径: ...` / `使用默认路径` | info |
| 系统检测 | `检测到客户端系统: ${os}` | info |
| API 调用 | `正在调用下载 API...` | info |
| API 响应 | `API 响应成功，获取到下载信息` | success |
| API 失败 | `API 请求失败 (HTTP 500): ...` | error |
| 下载方式 | `使用 OSS 直接下载` / `使用服务器代理下载` | info |
| 连接服务器 | `正在连接下载服务器...` | info |
| 接收数据 | `正在接收文件数据...` | info |
| 下载成功 | `下载成功！文件大小: 34.12 MB` | success |
| 下载失败 | `直接下载失败: Failed to fetch` | warning |
| 启用代理 | `尝试使用备用下载方式（代理下载）...` | info |
| 代理成功 | `代理下载成功！文件大小: 34.12 MB` | success |
| 代理失败 | `代理下载也失败: ...` | error |
| 创建链接 | `正在创建下载链接...` | info |
| 触发下载 | `触发浏览器下载: ${filename}.zip` | info |
| 完成 | `下载完成！请在浏览器下载文件夹中查找文件` | success |
